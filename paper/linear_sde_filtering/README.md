# Filtering Experiment

Re-run the Linear SDEs experiment for the paper "Particle-based inference for continuous-discrete state space models" here.

The details of the experiment are outlined in Secion X.X of the paper. To run the experiment, run the script: 

`source run_filtering_experiments.sh`

This will take around an hour. The results will then be available at `./results`.

The results plot can then be reproduced in the notebook `filtering_experiment_results.ipynb`
